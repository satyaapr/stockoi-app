# STOCK.OI

STOCK.OI adalah prototype web untuk **inventory status control**, **anomaly detection**, dan **operational visibility** di area manufaktur.

## Page yang tersedia
- Dashboard
- Smart Capture
- Validation
- Status Board
- Alert & Anomaly
- Movement Timeline
- Audit Trail
- Validation Report
- Material Master
- Location Master
- User Management
- Logout
- Review Detail per transaction

## Stack Yang Digunakan
- Next.js App Router
- React
- Tailwind CSS v4
- CSV data source via `csv-parse`

## How To Run Stock.OI
PENTING!!!
Gunakan Node.js versi 20+**.

Jalankan command berikut pada terminal :

npm install
npm run dev

JIKA TIDAK BISA GUNAKAN : 

npm.cmd install
npm.cmd run dev

Lalu buka:

http://localhost:3000
